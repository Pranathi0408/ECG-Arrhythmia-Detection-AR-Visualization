# ECG Arrhythmia Detection with AR-Based 3D Heart Visualization

## 📌 Overview
This project presents an intelligent healthcare solution for detecting cardiac arrhythmias from ECG signals using Deep Learning techniques and visualizing abnormalities through Augmented Reality (AR).

The system analyzes ECG data, classifies heart rhythm abnormalities using CNN and MLP models, and displays the affected cardiac regions on an interactive 3D heart model, helping improve diagnosis and understanding of cardiovascular conditions.

---

## 🎯 Objectives
- Detect arrhythmia automatically from ECG signals.
- Reduce dependence on manual ECG interpretation.
- Improve diagnostic accuracy using Deep Learning.
- Visualize affected heart regions through AR-based 3D models.
- Support better clinical understanding and decision-making.

---

## 🏗️ System Workflow
1. ECG Data Acquisition
